Study DESIGN.md, PLAN.md and TESTING.md

Refer to AGENT/current_phase.md. This tells you what phase of the PLAN you are currently implementing.

Refer to AGENT/TASKS.md.

If TASKS.md IS empty OR all tasks complete THEN
    - archive the the current task file with the current datetime under AGENT/_archive/
    - increment the phase in current_phase.md
    - generate a new task list for the next phase at AGENT/TASKS.md
    - git commit with an informative message
    - END TURN (return to user)
ELSE
    - implement ONE task on the task list
    - ensure task is thoroughly tested, and ALL tests pass
    - ONLY ONCE ALL TEST PASS, mark task as complete
    - git commit with an informative message
    - END TURN (return to user)
END

## Stopping the loop

You have the ability to stop the agent loop by creating a file at AGENT/STOP_LOOP.
Write a clear reason as the file content.

You MUST stop the loop (create AGENT/STOP_LOOP) when:
- A phase is marked as requiring human review (e.g. "🔶 Human Review Checkpoint" in TASKS.md)
- All phases in PLAN.md are complete and there is no more work to do
- You encounter an ambiguity or decision that needs human input
- Tests are failing in a way you cannot resolve after 2 attempts
- You need to modify DESIGN.md, PLAN.md, or TESTING.md (propose changes in STOP_LOOP, don't make them)

When stopping, write AGENT/STOP_LOOP with a clear explanation of why you stopped
and what action is needed from the human before resuming.
